1. What This System Does
This system allows a user or consultant to complete a structured, multi-module screening battery covering 9 major mental health and neurodegenerative disorder categories. Once completed, all module scores are sent to the Claude API, which analyzes the pattern of responses across modules and generates a structured clinical report. The report tells the consultant which disorder categories show early indicators, at what severity level, and what the recommended next steps are.
The system does not diagnose. It detects early warning patterns and produces a probability-weighted report that a licensed professional can act on. Think of it as an intelligent triage layer that sits between the user and clinical care.

The core loop in one sentence:
User completes targeted screening modules  ?  Scores sent to Claude API  ?  Claude analyzes cross-module patterns  ?  Structured report generated  ?  Consultant reviews and acts.

4. AI Analysis Engine — Claude API Integration
After all selected modules are completed, the system sends the full session payload to the Claude API. Claude analyzes cross-module score patterns, identifies co-occurring signals, and generates a structured clinical report. This is the core intelligence layer of the system.
4.1 Why Claude API Is the Right Phase 1 Choice
No training data required. Claude already understands clinical psychology domains deeply.
Handles nuance that rule-based systems cannot — e.g. a high PTSD score combined with a Monitor psychosis score suggests a different clinical picture than either in isolation.
Report output is natural language, readable by a consultant without technical interpretation.
Prompt can be updated without redeploying the app — iterate on report quality quickly.
Phase 2 migration path: collect session data now, train a custom model later on real labelled outcomes.

4.2 The Claude API Prompt Architecture
The prompt sent to Claude must contain: the system role (clinician assistant), the full score payload as structured JSON, and an explicit instruction on report format. Below is the exact prompt template to use.

SYSTEM PROMPT (send once, cached):
You are a clinical decision-support assistant helping a licensed mental health consultant interpret a multi-module screening battery. Your role is to analyze score patterns across disorder categories, identify likely early-indicator clusters, note co-occurring signals, and produce a structured report. You do not diagnose. You produce probability-weighted clinical observations and recommended next steps. Always use careful, non-alarmist language. Always note that findings are screening signals only.
USER PROMPT TEMPLATE (send per session):
A user has completed a mental health screening battery. Below is their full score data. Please analyze the cross-module patterns and generate a structured clinical report using the format specified.
SESSION DATA:
{ [full JSON session payload — see Section 5] }
Generate the report in exactly this structure:
1. SUMMARY: 2–3 sentence overview of the most notable findings.
2. DISORDER SIGNALS: For each module with Monitor or Elevated score, list: Disorder category | Score band | Key symptom clusters flagged | Clinical note.
3. CO-OCCURRING PATTERNS: Note any combinations of module scores that together suggest a more specific or complex clinical picture.
4. SAFETY FLAGS: List any critical items triggered (suicidal ideation, self-harm, psychosis items M3.1–3.4).
5. RECOMMENDED NEXT STEPS: Specific, actionable referral suggestions for the consultant.
6. DISCLAIMER: Standard screening-only disclaimer.

4.3 API Call Implementation (Flutter / Dart)
// In your Flutter service layer:
Future<String> generateReport(Map<String, dynamic> sessionData) async {
final response = await http.post(
Uri.parse('https://api.anthropic.com/v1/messages'),
headers: {
'x-api-key': YOUR_API_KEY,
'anthropic-version': '2023-06-01',
'content-type': 'application/json',
},
body: jsonEncode({
'model': 'claude-sonnet-4-6',
'max_tokens': 2000,
'system': SYSTEM_PROMPT,  // from Section 4.2
'messages': [{'role': 'user', 'content': buildPrompt(sessionData)}]
}),
);
return jsonDecode(response.body)['content'][0]['text'];
}

Important: Never call the Claude API directly from the Flutter client. Route all API calls through your backend server. This protects your API key and allows you to log sessions before the report is generated.

6. Escalation & Safety Framework
Tier	Level	Trigger	System Action	UX Behaviour
1	No Flag	All modules Low	Log session. Generate report. No alert.	Green result screen. Wellness resources optional.
2	Monitor	Any module reaches Monitor band	Flag in DB. Generate AI report. Prompt GP discussion.	Amber screen. Encourage professional conversation.
3	Elevated — Refer	Any module Elevated, OR M7.5 triggered	Flag in DB. Generate AI report. Push referral resources. Alert consultant if in session.	Red screen. Referral copy shown prominently. AI report unlocked for consultant.
4	CRISIS	M1.12 extreme + M7.5 YES, OR any active suicidal ideation item	INTERRUPT. Block flow. Log critical event. Trigger crisis protocol immediately.	Full-screen crisis card. 988 + 911 shown. No further navigation until acknowledged.

MENTAL HEALTH SCREENING REPORT — SESSION #A3F29B
Generated by AI Analysis Engine | Screening Only — Not Diagnostic
1. SUMMARY
This session shows elevated indicators across Depression & Anxiety (M1), Bipolar/Mania (M2), and PTSD (M6), with a notable Parkinson’s-type neurological signal cluster in M9. The co-occurrence of elevated mood cycling with PTSD indicators warrants careful differential consideration. No active crisis items were triggered.
2. DISORDER SIGNALS
Depression & Anxiety (M1) — MONITOR (Score: 18/48) | Key clusters: Persistent low mood, anhedonia, sleep disturbance, concentration difficulty. Clinical note: Scores are significant but sub-threshold for Elevated. Monitor for progression, particularly items M1.2 and M1.4.
Bipolar / Mania (M2) — ELEVATED (Score: 26/44) | Key clusters: Mood cycling, decreased sleep need, impulsivity, grandiosity. Clinical note: Pattern is consistent with hypomanic episode indicators. Cycling pattern (M2.2) combined with functional impact (M2.10) warrants priority evaluation.
PTSD (M6) — ELEVATED (Score: 31/44) | Key clusters: Re-experiencing, hypervigilance, emotional numbing, sleep disturbance. Trauma disclosed (M6.1 = Yes). Clinical note: Score is in the clinically significant range. Avoidance and numbing subscores are particularly high.
3. CO-OCCURRING PATTERNS
The combination of elevated mood cycling (M2) with high PTSD indicators (M6) is clinically meaningful. Trauma-related mood dysregulation can mimic or co-occur with Bipolar II. The consultant should explore chronological onset — whether mood cycling predated the traumatic experience or emerged following it — before drawing conclusions about primary diagnosis direction.
4. SAFETY FLAGS
No Tier 4 crisis items triggered. M7.5 (self-harm) was not endorsed. Passive hopelessness item M1.12 scored 3 (Often) — recommend direct clinical inquiry about this in consultation.
5. RECOMMENDED NEXT STEPS
a) Priority referral to a psychiatrist or psychologist for structured clinical interview regarding Bipolar II and PTSD.
b) Neurology consultation recommended given Parkinson’s cluster (M9.5, M9.6, M9.8, M9.9, M9.11 all endorsed). Progressive onset confirmed (M9.12 = Yes).
c) Directly assess hopelessness and passive suicidal ideation at first clinical contact given M1.12 score.
6. DISCLAIMER
This report is generated from a self-report screening battery and is for educational and research purposes only. It does not constitute a clinical diagnosis and must not be used as the sole basis for any clinical decision. Results should be interpreted by a licensed healthcare professional in the context of a full clinical assessment.
